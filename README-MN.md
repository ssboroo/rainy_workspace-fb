# RAINY FB Pro 5.6.8

Монгол хэлтэй Facebook ажлын Chrome өргөтгөл. Пост бэлтгэх, группийн жагсаалт удирдах, нийтлэлийн дараалал ба хуваарь тохируулах, явц хянах, хэрэглэгчид харагдаж буй зарын мэдээллийг шүүж CSV экспортлоход зориулагдсан.

## Хэнд зориулагдсан бэ?

- Хувь хүн, контент бүтээгч
- Жижиг бизнес, онлайн худалдаа
- Үйлчилгээний байгууллага
- Маркетер, Facebook групп админ
- Үл хөдлөх хөрөнгийн зуучлагч

## Хэрэглэгчийн суулгалт

1. [5.6.8 ZIP багц](https://workspace.rainy.studio/downloads/rainy-fb-pro-5.6.8.zip)-ийг татаж бүрэн задална.
2. Chrome хаягийн мөрөнд `chrome://extensions` нээнэ.
3. Developer mode-ийг асаана.
4. Load unpacked дарж `manifest.json` байгаа задалсан хавтсыг сонгоно.
5. RAINY FB Pro-г Pin хийгээд Facebook tab-аа refresh хийнэ.

Гараар суулгасан ZIP хувилбар Chrome Web Store-ийн автомат шинэчлэлтийг авахгүй. Шинэ багц гарвал дахин татаж, extension хуудсанд Reload хийнэ.
# RAINY FB Pro 5.8.0 — Release Candidate

Монгол хэлтэй, Facebook-д зориулсан Chrome өргөтгөл. Facebook группийн нийтлэл бэлтгэх, нийтлэх ажлын дараалал удирдах, хуваарь тохируулах, групп болон зарын мэдээлэл хайх, төхөөрөмжийн лицензээ шалгахад зориулагдсан.

> **Хувилбарын төлөв:** 5.8.0 нь release candidate салбар дээрх хувилбар. Chrome Web Store-д нийтлэгдсэн гэж үзэхгүй. Бодит Facebook хэрэглэгчийн туршилт болон Store-ийн нийтлэлт тусдаа баталгаажуулалт шаарддаг.

## Хэнд зориулагдсан бэ?

- Хувь хүн, контент бүтээгч
- Жижиг бизнес, онлайн худалдаа эрхлэгч
- Үйлчилгээний байгууллага
- Маркетер болон Facebook группийн админ
- Үл хөдлөх хөрөнгийн зуучлагч

## Гол боломжууд

### Пост бэлтгэх, группт нийтлэх
- Постын текст, зураг бэлтгэх; текстийн загвар хадгалах.
- Facebook группийн холбоосыг жагсаалт болгон оруулах, группийн багц/preset хадгалах.
- Нийтлэх дарааллыг холих, групп хоорондын завсарлага тохируулах.
- Queue эхлүүлэх, түр зогсоох, үргэлжлүүлэх, зогсоох; явц болон ажиллагааны лог харах.
- Зургийг хэмжээгээр хөнгөрүүлэх, EXIF/metadata-г арилгах сонголттой. Зураг боловсруулах үед формат, чанар өөрчлөгдөж болно.

### Хуваарь ба давхардлын хяналт
- Нэг удаагийн болон тогтмол давтамжтай хуваарь.
- Давтамжийн сонголт, ажиллах цагийн хүрээ (Asia/Ulaanbaatar).
- Тодорхойгүй эсвэл админы хяналт хүлээж буй нийтлэлийг автоматаар давтан илгээхгүй байх хамгаалалт.
- Компьютер унтарсан хугацааны хуваарийг бөөнөөр нөхөж нийтлэхгүй.

### Групп хайлт
- Facebook группийг түлхүүр үгээр хайх.
- Нэвтэрсэн хэрэглэгчийн нэгдсэн группүүдийг харах.
- Хайлтын үр дүнгээс сонгосон группүүдийг нийтлэлийн жагсаалтад нэмэх.
- Автоматаар группт нэгдэх сонголт байгаа боловч хэрэглэгчийн сонголт, Facebook-ийн зөвшөөрөл болон хязгаарлалтаас хамаарна.

- Постын текст, зураг, загвар бэлтгэх, хадгалах.
- Группийн жагсаалт болон preset удирдах.
- Сонгосон группүүдэд нийтлэх дараалал, нэг удаагийн болон давтамжтай хуваарь тохируулах.
- Queue-ийн явц, алдаа, тодорхойгүй төлөвийг хянах.
- Харагдаж буй нийтлэлээс зарын мэдээлэл шүүж CSV экспортлох.
- Төхөөрөмжийн trial, төлбөрийн захиалга, лицензийн хугацааг харах.

## Trial, лиценз, төлбөр

- Шинэ төхөөрөмжийн туршилтын эрх болон төлбөртэй багцын үнэ нь өргөтгөлийн Лиценз хэсэгт харагдана.
- Төлбөрийн хүсэлт, дүн, төлөвийг сервер баталгаажуулна.
- Банкны картын мэдээллийг өргөтгөлд хадгалахгүй.
- Бодит төлбөрийн урсгалыг хэрэглэгчийн тест захиалгаар тусад нь баталгаажуулах шаардлагатай.

## Аюулгүй ажиллагааны хязгаар

Facebook-ийн нэвтрэлт, группийн зөвшөөрөл, checkpoint, платформын UI өөрчлөлт болон нийтлэх хязгаарлалтаас шалтгаалан зарим үйлдэл зогсож болно. Тодорхойгүй илгээлтийг автоматаар дахин илгээхгүй байх хамгаалалттай. Энэ нь Facebook-ийн block эсвэл хязгаарлалтаас 100% хамгаалах баталгаа биш. Өргөтгөл нь Facebook/Meta-тай холбоогүй.

### Зар / утасны дугаар хайлт
- Түлхүүр үг эсвэл Facebook холбоосоор харагдаж буй зарын мэдээлэл хайх.
- Утасны дугаартай үр дүнгээр шүүх, үр дүнг хайлтаар дахин шүүх.
- CSV файл болгон экспортлох, илэрсэн дугааруудыг хуулах.
- Хайлтын үр дүн нь Facebook-д тухайн хэрэглэгчид харагдаж буй мэдээллээр хязгаарлагдана; бүх пост, бүх группийг бүрэн хамарна гэсэн баталгаа биш.

### Лиценз ба төлбөр
- Төхөөрөмжийн trial болон лицензийн төлөв, дуусах хугацааг харах.
- Лицензийн түлхүүр идэвхжүүлэх.
- Төлбөрийн багц сонгох, нэхэмжлэл болон төлбөрийн төлөв шалгах интерфэйс.
- QPay / Wire төлбөрийн checkout нь серверийн эзэмшигчийн тохиргоо болон үйлчилгээний бэлэн байдлаас хамаарна. Бодит төлбөрийн урсгалыг тусдаа тест захиалгаар шалгана.

## Суулгах

1. [Татах хуудас](https://workspace.rainy.studio/download/)-аас тухайн үед санал болгож буй багцыг авна.
2. ZIP файлыг бүрэн задална.
3. Chrome дээр `chrome://extensions` нээнэ.
4. **Developer mode**-ийг асаана.
5. **Load unpacked** дарж `manifest.json` байгаа хавтсыг сонгоно.
6. Өргөтгөлийг Pin хийгээд Facebook tab-аа refresh хийнэ.

Гараар суулгасан хувилбар Chrome Web Store-ийн автомат шинэчлэлтийг авахгүй. Шинэ хувилбар суулгахдаа өмнөх өргөтгөлийн хавтсыг шинэ багцаар сольж, Chrome Extensions хуудсанд Reload хийнэ.

## Шаардлага

- Google Chrome 120 болон түүнээс дээш.
- Facebook-д нэвтэрсэн хэрэглэгчийн Chrome профайл.
- Группт нийтлэх, хайх үйлдэлд тухайн Facebook аккаунтын зохих эрх.
- Лиценз болон төлбөрийн онлайн шалгалтад интернет холболт.

## Аюулгүй ажиллагаа ба хязгаарлалт

- Өргөтгөл зөвхөн Facebook веб орчинд ажиллахаар тохируулагдсан.
- Facebook-ийн UI өөрчлөлт, нэвтрэлт, checkpoint, группийн эрх, платформын хязгаарлалт зэргээс шалтгаалан үйлдэл зогсож болно.
- `UNKNOWN` буюу баталгаажаагүй төлөвийг амжилттай нийтэлсэн гэж тооцохгүй. Эх групп дээрээс гараар шалгана.
- Өргөтгөл нь Facebook/Meta-тай холбоогүй бөгөөд block, checkpoint, хязгаарлалтаас 100% хамгаална гэсэн баталгаа өгөхгүй.
- Зөвхөн өөрийн эсвэл ашиглах зөвшөөрөлтэй групп, аккаунт, мэдээлэл дээр ажиллуулна. Нийтлэхээс өмнө агуулга, зорилтот группээ шалгана.
