# RAINY FB Pro 5.8.0

Монгол хэлтэй Facebook ажлын Chrome өргөтгөл. Пост бэлтгэх, группийн жагсаалт удирдах, нийтлэлийн дараалал ба хуваарь тохируулах, явц хянах, хэрэглэгчид харагдаж буй зарын мэдээллийг шүүж CSV экспортлоход зориулагдсан.

> **Хувилбарын төлөв:** 5.8.0 нь эх кодын release хувилбар. Chrome Web Store-д нийтлэгдсэн эсэх, бодит Facebook нийтлэл болон төлбөрийн урсгалыг тусад нь баталгаажуулна.

## Хэнд зориулагдсан бэ?

- Хувь хүн, контент бүтээгч
- Жижиг бизнес, онлайн худалдаа
- Үйлчилгээний байгууллага
- Маркетер, Facebook групп админ
- Үл хөдлөх хөрөнгийн зуучлагч

## Гол боломжууд

### Пост ба групп
- Постын текст, зураг бэлтгэх; текстийн загвар хадгалах.
- Facebook группийн холбоос оруулах, группийн багц/preset хадгалах.
- Нийтлэх дараалал, групп хоорондын завсарлага тохируулах.
- Queue эхлүүлэх, түр зогсоох, үргэлжлүүлэх, зогсоох; явц болон ажиллагааны лог харах.
- Зургийг хөнгөрүүлэх, EXIF/metadata арилгах сонголт.

### Хуваарь ба хамгаалалт
- Нэг удаагийн болон тогтмол давтамжтай хуваарь.
- Улаанбаатарын цагийн бүсээр ажиллах цаг тохируулах.
- Тодорхойгүй эсвэл админы хяналт хүлээж буй нийтлэлийг автоматаар дахин илгээхгүй.
- Queue сэргээх үед илгээгдээгүй алхмыг буцаан дараалалд оруулж, илгээлт эхэлсэн ч үр дүн тодорхойгүй болсон алхмыг UNKNOWN гэж тэмдэглэнэ.
- Facebook checkpoint/restriction илэрвэл ажиллагааг зогсооно; хязгаарлалтыг тойрохгүй.

### Групп хайлт ба Lead Finder
- Түлхүүр үгээр групп хайх, нэгдсэн группүүдийг харах.
- Хэрэглэгчид харагдаж буй зарын мэдээллийг шүүх.
- Утастай зар ялгах, CSV экспортлох, илэрсэн дугаар хуулах.

### Лиценз ба нөөц
- Төхөөрөмжийн trial/лицензийн төлөв, хугацааг харах.
- Төлбөрийн багц сонгох, нэхэмжлэл болон төлбөрийн төлөв шалгах.
- Тохиргооны JSON нөөц үүсгэх, нөөцөөс сэргээх.

## Суулгах

1. [Татах хуудас](https://workspace.rainy.studio/download/)-аас тухайн үед санал болгож буй ZIP багцыг татна.
2. ZIP файлыг бүрэн задална.
3. Chrome дээр `chrome://extensions` нээнэ.
4. **Developer mode**-ийг асаана.
5. **Load unpacked** дарж `manifest.json` байгаа хавтсыг сонгоно.
6. Өргөтгөлийг Pin хийгээд Facebook tab-аа refresh хийнэ.

Гараар суулгасан ZIP хувилбар Chrome Web Store-ийн автомат шинэчлэлтийг авахгүй. Шинэ багц гарвал татаж, Extensions хуудсанд Reload хийнэ.

## Шаардлага

- Google Chrome 120 болон түүнээс дээш.
- Facebook-д нэвтэрсэн Chrome профайл.
- Группт нийтлэх, хайх үйлдэлд тухайн аккаунтын зохих эрх.
- Лиценз болон төлбөрийн онлайн шалгалтад интернет холболт.

## Аюулгүй ажиллагаа ба хязгаарлалт

Facebook-ийн нэвтрэлт, группийн зөвшөөрөл, checkpoint, платформын UI өөрчлөлт болон нийтлэх хязгаарлалтаас шалтгаалан зарим үйлдэл зогсож болно. `UNKNOWN` буюу баталгаажаагүй төлөвийг амжилттай нийтэлсэн гэж тооцохгүй; эх групп дээрээс гараар шалгана. Өргөтгөл нь Facebook/Meta-тай холбоогүй бөгөөд block, checkpoint, хязгаарлалтаас 100% хамгаалах баталгаа өгөхгүй. Зөвхөн өөрийн эсвэл ашиглах зөвшөөрөлтэй групп, аккаунт, мэдээлэл дээр ажиллуулна.
