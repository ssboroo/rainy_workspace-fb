Суулгах заавар

  1. Татсан ZIP файлаа Windows дээр Extract All ашиглан бүрэн задлана.
  2. Chrome хаягийн мөрөнд chrome://extensions гэж оруулна.
  3. Developer mode-ийг асаана.
  4. Load unpacked дарж, задласан хавтас доторх manifest.json-тай хавтсыг сонгоно.
  5. RAINY FB Pro-г Pin хийгээд Facebook-д нэвтэрсэн tab-аа refresh хийнэ.

Энэ нь Chrome Web Store-оос суулгасан хувилбар биш, гараар суулгах багц юм. Ийм суулгалт Chrome Web Store-ийн автомат шинэчлэлтийг авахгүй; шинэ хувилбар гарвал ZIP-ийг дахин татаж Reload хийнэ.
